1. Questão colocada

"Não entendi porque precisamos de ter Claude API (extração estruturada) + OpenAI (triagem e Whisper), pois isso irá obrigar o cliente a contratar 2 contas de IA, certo? Dado que cada conta tem um custo mensal, existe alguma possibilidade de contratar somente o Claude e usar ou isso sai muito caro? Qual a análise de custos para esse uso?"

Questão pertinente, e vale a pena respondê-la em detalhe, porque assenta num pressuposto que convém corrigir antes de qualquer decisão.

2. Resposta curta

  1. Não existe custo mensal fixo. As contas de API — quer da Anthropic (Claude), quer da OpenAI — não são subscrições. São contas pré-pagas por consumo: carrega-se saldo e desconta-se apenas o que é efetivamente utilizado. Ter duas contas abertas não gera dois encargos mensais. Não gera encargo nenhum, enquanto não houver consumo.
  2. A única coisa que o Claude não faz é transcrever áudio. Todo o resto — extração estruturada e triagem de e-mail — o Claude executa sozinho, sem necessidade da OpenAI.
  3. Essa transcrição é, no âmbito atual, apenas um plano de recurso (fallback). O PLAUD já entrega a transcrição feita. Em operação normal, a conta OpenAI fica com consumo próximo de zero.
  4. Sim, é perfeitamente possível avançar só com o Claude. O impacto está quantificado na secção 6.
  5. Em qualquer dos cenários, o valor em causa é de poucos euros por mês — a diferença entre as duas arquiteturas situa-se entre €1,30 e €1,80 por mês.

3. Desfazer o pressuposto: API não é subscrição

Convém separar dois produtos que partilham a mesma marca e são frequentemente confundidos:

Aplicação de chat (Claude Pro, ChatGPT Plus)API (o que este projeto usa)
Modelo comercialSubscrição mensal fixaPré-pago por consumo
Custo se não usarCobrado na mesmaZero
Como se pagaDébito automático mensalCarrega-se saldo; desconta à medida do uso
Encargo mínimo~€20/mês por utilizadorCarregamento inicial de saldo [A CONFIRMAR: valor mínimo à data da contratação — habitualmente na ordem dos 5 USD em ambos os fornecedores]

O projeto não usa as aplicações de chat. Usa exclusivamente as APIs, integradas no n8n.

Consequência prática: manter as duas contas abertas não custa nada. O que custa é o número de e-mails triados, de transcrições processadas e de contratos lidos. Uma conta parada é uma conta a €0.

4. Porque é que existem duas na proposta

A repartição não foi feita por preferência de marca, mas por competência técnica de cada motor:

TarefaMotor propostoO Claude consegue fazer sozinho?
Extração estruturada de contratos e transcrições longasClaudeSim — é precisamente o ponto forte dele
Triagem e classificação de e-mailOpenAI (modelo económico)Sim — o Claude faz o mesmo, com qualidade equivalente
Transcrição de áudio (voz → texto)OpenAI — gpt-4o-transcribeNão. O Claude não processa áudio

Ou seja: de três tarefas, duas são indiferentes ao fornecedor. A OpenAI entrou na proposta por uma única razão — a transcrição de áudio — e por um motivo secundário: para triagem em massa, o modelo mais económico da OpenAI é mais barato do que o mais económico do Claude. Como se verá, essa diferença traduz-se em cêntimos.

5. A transcrição por API é plano de recurso, não é o caminho principal

Este ponto é decisivo para a decisão.

Na arquitetura proposta, a transcrição das chamadas não é feita por IA contratada. É feita pelo PLAUD, que grava a chamada e devolve a transcrição já pronta, que segue via Zapier para o n8n. A transcrição está paga dentro do plano PLAUD.

A transcrição por API existe na proposta apenas para cobrir uma hipótese: gravações que não venham do PLAUD — uma reunião gravada no telemóvel, uma mensagem de voz de WhatsApp de um cliente, um áudio enviado por um colega.

Se essa hipótese não se materializar, esse motor nunca é chamado e a conta OpenAI fica com consumo de €0 — ou pode simplesmente nunca ser criada.

6. Pode avançar-se só com o Claude? Sim.

Resposta direta: sim, é tecnicamente viável e não compromete nenhum dos 12 módulos do escopo.

O que se perde, exatamente:

ItemImpacto de usar só Claude
Extração estruturada de contratos e transcriçõesNenhum. Já é Claude na proposta
Triagem de e-mailNenhum impacto funcional. Passa a Claude Haiku. Custa alguns cêntimos a mais por mês
Transcrição de chamadas via PLAUDNenhum. Não depende de IA contratada
Transcrição de áudio fora do PLAUDPerde-se. Áudios que não passem pelo PLAUD teriam de ser transcritos manualmente

Formas de resolver a única lacuna, se e quando ela aparecer:

  1. Canalizar tudo pelo PLAUD — a via mais simples. Se todas as chamadas relevantes passam pelo gravador, a lacuna não existe.
  2. Ativar a conta OpenAI só quando a necessidade for real. Como o n8n desacopla o fornecedor, ligar a transcrição por API mais tarde é uma alteração pontual num único nó do fluxo — não obriga a rever a arquitetura.
  3. Recorrer a um serviço alternativo de transcrição (gpt-4o-transcribe, Deepgram ou equivalente), contratado nesse momento e igualmente pré-pago.

Nenhuma destas opções exige decisão hoje.

8. Recomendação

Manter as duas contas em aberto como possibilidade, mas usar apenas o Claude no arranque.

É a opção que reúne o melhor dos dois lados e não implica custo nenhum:

  1. Criar apenas a conta Claude na entrada em produção. Cobre extração estruturada e triagem de e-mail. Uma só conta para gerir, um só saldo para vigiar.
  2. Não criar a conta OpenAI enquanto não houver necessidade real. Enquanto o PLAUD entregar as transcrições, a transcrição por API é dispensável.
  3. Se aparecerem áudios fora do PLAUD, abre-se a conta OpenAI nesse momento. Como está tudo desacoplado no n8n, a ligação é um ajuste pontual num nó do fluxo — sem custo adicional dentro do âmbito atual.

Ganha-se simplicidade administrativa e perde-se, no máximo, cerca de €1,80 por mês face ao desenho original. Uma troca claramente favorável.

O que proponho fazer, sem alteração de escopo, prazo ou investimento:

  • Reformular a camada de IA para Claude como fornecedor único, com a transcrição por API mantida apenas como opção documentada, a ativar se necessário.
  • Incluir na Fase 1 a medição do consumo real dos primeiros dias, para substituir estas estimativas por números concretos da operação.
  • Configurar, na Fase 4, um alerta de saldo na conta Claude, garantindo que nunca há interrupção por falta de crédito nem surpresas de faturação.
